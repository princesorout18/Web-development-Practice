Q14. Rest parameters and spread syntax 
Predict both outputs and explain the difference between the two function calls. 
function addNumbers(...numbers) { 
return numbers.length; 
} 
const values = [10, 20, 30, 40]; 
console.log(addNumbers(values)); 
console.log(addNumbers(...values)); 

output:
1
4


Explanation:

First call: addNumbers(values)

The entire array is passed as one argument. Therefore, numbers becomes [[10, 20, 30, 40]], which has a length of 1.

Second call: addNumbers(...values)

The spread operator ... expands the array into four separate arguments. The rest parameter collects them into [10, 20, 30, 40], which has a length of 4.

Remember:
- Rest ... collects multiple arguments into an array.
- Spread ... expands an array or another iterable into individual elements.

Q16. Fix the shopping cart calculation 
Identify the logical error, correct the loop, and explain why the original code produces an incorrect result. 
function calculateCartTotal(...prices) { 
let total = 0; 
for (let i = 0; i <= prices.length; i++) { 
total += prices[i]; 
} 
return total; 
} 
console.log(calculateCartTotal(100, 200, 300));

Problem: The loop condition uses i <= prices.length, which goes one position beyond the last valid array index.

corrected code:

function calculateCartTotal(...prices) {
    let total = 0;

    for (let i = 0; i < prices.length; i++) {
        total += prices[i];
    }

    return total;
}

console.log(calculateCartTotal(100, 200, 300));

output: 600

Explanation:

The array contains three elements at indexes 0, 1, and 2. The condition i <= prices.length also tries to access index 3, which gives undefined.

Adding undefined to the total makes it NaN. Using i < prices.length prevents this error.

   Q19. Scope and Hoisting  
console.log(a); 
var a = 10; 
console.log(b); 
let b = 20; 
● Which statement executes successfully? 
● Which statement produces an error? 
● Explain the role of hoisting and the Temporal Dead Zone (TDZ).

Output:
undefined
ReferenceError


Explanation:
- console.log(a) executes successfully and prints undefined.
- var a is hoisted, meaning its declaration is processed before the code runs. Its value is initially undefined until the assignment a = 10 executes.
- console.log(b) causes a ReferenceError because b is accessed before its let declaration is initialized.
- The period between entering the scope and initializing a let or const variable is called the Temporal Dead Zone (TDZ).
Which statement executes successfully?

console.log(a) executes successfully.

Which statement produces an error?

console.log(b) produces a ReferenceError.

Important: If the code is executed as one script, the error on b stops normal execution, so let b = 20 is not reached.


                             JavaScript Interview-Level Questions


1. What is the difference between == and ===? 
Answer:
- == compares values after performing type conversion when needed.
- === compares both value and data type without type conversion.

2. What is the difference between undefined and null? 
Answer:
- undefined means a variable has been declared but has not been assigned a value.
- null represents an intentionally empty or absent value.

3. What is the difference between for...in and for...of? 
Answer:
- for...in iterates over enumerable property keys, such as an object's property names or an array's indexes.
- for...of iterates over values of iterables, such as arrays and strings.

4. Can a function return another function? Give a real-world use case.
Answer: Yes. A function can return another function. This is useful for creating reusable functions and maintaining private data through closures

5. What happens if a function has no explicit return statement? 
Answer: The function returns undefined by default.

6. What is the difference between passing a primitive value and passing an object to a function? 
Answer:

Primitive values include numbers, strings, booleans, null, undefined, bigint, and symbols. JavaScript passes their values to functions. Objects are also passed by value, but that value is a reference to the object.

7. What is the difference between shallow copying and deep copying an object? 
Answer:
- A shallow copy copies the top-level properties, but nested objects are still shared.
- A deep copy also copies nested objects, so changes to the copied nested data do not affect the original

8. Why is NaN !== NaN true?
Answer: NaN means Not a Number. In JavaScript, NaN is not equal to any value, including itself.

9. What is the difference between function declarations and function expressions regarding 
hoisting? 
Answer:
- A function declaration can generally be called before its position in the code because the function declaration is hoisted with its function body.
- A function expression assigned to a let or const variable cannot be called before the variable is initialized.

10. When would you use an arrow function instead of a regular function?
Answer: Arrow functions are useful for short callbacks and situations where you want to inherit this from the surrounding scope.
